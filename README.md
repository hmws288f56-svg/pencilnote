# 펜슬노트

아이패드에 애플펜슬로 쓰면 같은 Wi-Fi의 노트북 화면에 바로 나타나고, 필기는 노트북에 저장되는 프로그램.

- **아이패드 앱** (`ios/`) — Apple 순정 필기 엔진(PencilKit)으로 쓰고, 획을 노트북으로 보냄
- **노트북 프로그램** (`pc/`) — 필기를 받아 화면에 보여 주고 저장. 노트·페이지 관리, PNG/PDF 내보내기

## 쓰는 법

1. **노트북**에서 `펜슬노트 시작.bat` 더블클릭 → 검은 창이 뜨고 브라우저에 펜슬노트 화면이 열림
   - 처음 실행할 때 Windows 방화벽 창이 뜨면 **액세스 허용**
   - 검은 창을 닫으면 종료됨
2. **아이패드**에서 펜슬노트 앱 열기 → `자동으로 찾기` → 노트북 화면 왼쪽 아래의 **연결 코드** 6자리 입력 → `연결`
   - 처음에 "로컬 네트워크의 기기를 찾고 연결" 허용 창이 뜨면 **허용** (허용한 뒤 `자동으로 찾기`를 한 번 더)
   - 연결 코드는 **처음 한 번만** 필요함. 등록되면 다음부터는 앱만 열면 자동으로 붙음
   - 처음 등록은 집 Wi-Fi나 내 핫스팟처럼 믿을 수 있는 곳에서 할 것
3. 애플펜슬로 쓰면 노트북 화면에 나타남

### 아이패드

| 하는 일 | 방법 |
| --- | --- |
| 펜·형광펜·지우개·올가미·색 | 화면의 도구 막대 (Apple 메모 앱과 같음) |
| 스크롤 / 확대 | 손가락으로 밀기 / 두 손가락으로 벌리기 |
| 실행 취소 / 다시 실행 | 위쪽 ↶ ↷ |
| 페이지 넘기기 / 추가 | 위쪽 ‹ › ＋ |
| 연결 설정 | 왼쪽 위 노트북 아이콘 |

노트북과 연결이 끊겨도 계속 쓸 수 있고, 다시 연결되면 그동안 쓴 것이 올라감.

### 노트북

- 왼쪽: 노트 목록, 새 노트, 아이패드 연결 상태·주소·연결 코드
- 위쪽: 노트 제목(눌러서 수정), 페이지 넘기기·추가, 종이 종류(무지/줄/모눈/점), 보기 방식, 비우기, PNG, PDF, 크게 보기
- 오른쪽: 페이지 미리보기 (눌러서 이동, 마우스를 올리면 순서 바꾸기·삭제)
- **아이패드 화면** 보기: 아이패드에서 보고 있는 부분을 크게 보여 줌 / **페이지 전체** 보기: 한 장 전체
- 키보드: `←` `→` 페이지 넘기기, `F` 필기만 크게 보기
- PDF: `PDF` 버튼 → 인쇄 창에서 대상을 **PDF로 저장**으로 선택

### 저장 위치

`문서\PencilNote` 폴더.

- `library.json` 노트 목록, `pages\` 페이지별 필기 원본(.drawing)과 그림(.png)
- 삭제하거나 비운 것은 바로 지워지지 않고 `trash\` 폴더로 옮겨짐
- `config.json` 연결 코드와 등록된 기기 목록
- `tls-key.pem`, `tls-cert.pem` 이 노트북의 인증서. **지우거나 남에게 주지 말 것** (지우면 아이패드를 다시 등록해야 함)

## 아이패드에 앱 설치 (SideStore)

아이폰에 했던 것과 같은 과정을 **아이패드에도** 한 번 해야 함.

1. 아이패드를 PC에 연결 → iloader로 SideStore 설치 (공식: iloader.app)
2. 아이패드: 개발자 모드 켜기, 앱 신뢰, LocalDevVPN, 로컬 네트워크·알림 허용
3. 아이패드 Safari에서 릴리스 목록을 열어 최신 `PencilNote.ipa` 받기
   - https://github.com/hmws288f56-svg/pencilnote/releases
4. LocalDevVPN 켜기 → SideStore → My Apps → `+` → 받은 IPA 선택
5. 설치가 끝나면 **LocalDevVPN 끄기** (켜 둔 채로는 노트북을 못 찾을 수 있음)

기억할 것

- 무료 계정이라 7일마다 SideStore에서 Refresh (SideStore 자신 + 펜슬노트)
- 무료 계정은 기기당 앱 3개까지 (아이패드: SideStore + 펜슬노트 = 2개 사용)

## 수정하고 다시 빌드

노트북 프로그램(`pc/`)은 고친 뒤 `펜슬노트 시작.bat`을 다시 실행하면 바로 반영됨. 빌드 필요 없음.

아이패드 앱(`ios/`)은 GitHub에 올리면 자동으로 IPA가 만들어짐.

```bash
git add -A
git commit -m "수정 내용"
git push
```

- 3~5분 뒤 릴리스 목록에 새 IPA(Build 2, 3, ...)가 올라옴 → 아이패드에서 받아 SideStore로 다시 설치 (기존 앱 위에 덮어씀)
- 진행 상황: https://github.com/hmws288f56-svg/pencilnote/actions
- 빌드가 실패하면 릴리스 목록에 `Build N 실패`가 생기고 거기에 오류 내용과 로그(build.log)가 붙음
- 푸시가 "Permission denied to quaquakang-ai"로 거부되면 계정이 잘못 잡힌 것. 저장소 주소를 아래 형태로 써야 함
  `https://hmws288f56-svg@github.com/hmws288f56-svg/pencilnote.git`

### 아이패드 없이 노트북 화면 시험하기

```bash

```

## 연결이 안 될 때

1. 아이패드와 노트북이 **같은 Wi-Fi**인지 (카페·학교 Wi-Fi는 기기끼리 통신을 막아 둔 경우가 있음 → 휴대폰 핫스팟에 둘 다 연결하면 됨)
2. 노트북에서 검은 창(펜슬노트)이 켜져 있는지
3. Windows 방화벽: 처음에 "허용"을 누르지 않았다면
   설정 → 개인 정보 및 보안 → Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용 → `Node.js JavaScript Runtime`의 **개인·공용** 체크
4. 아이패드: 설정 → 개인정보 보호 및 보안 → 로컬 네트워크 → 펜슬노트 켜기
5. 아이패드의 VPN(LocalDevVPN 등) 끄기
6. `자동으로 찾기`가 안 되면 노트북 화면 왼쪽 아래의 **주소**를 직접 입력

## 보안 (공용 Wi-Fi에서 쓸 때)

- 아이패드 ↔ 노트북 통신은 모두 암호화(TLS)됨. 같은 Wi-Fi의 다른 사람이 필기 내용을 엿볼 수 없음
- 아이패드는 등록할 때 본 노트북 인증서를 기억하고, 다른 인증서를 내미는 기기에는 붙지 않음 (누가 노트북인 척해도 연결되지 않음)
- 연결 코드는 처음 등록할 때만 쓰고, 그 뒤로는 기기마다 따로 발급된 긴 비밀키로 인증함. 코드를 10번 틀리면 5분간 막힘
- 노트북 화면(노트 보기·관리)은 그 노트북 안에서만 열림. 다른 기기에서는 주소를 알아도 열 수 없음
- 아이패드를 잃어버렸거나 코드가 새어 나간 것 같으면: 노트북 화면 왼쪽 아래 **모두 해제** → 등록이 전부 지워지고 연결 코드가 새로 만들어짐

주의할 것

- **처음 등록(연결 코드 입력)은 집 Wi-Fi나 내 핫스팟에서.** 이때 한 번은 인증서를 처음 보는 것이라 진짜인지 가려낼 수 없음. 등록한 뒤로는 공용 Wi-Fi에서도 안전함
- 암호화와 별개로, 카페·학교 Wi-Fi가 기기끼리의 통신 자체를 막아 두면 연결이 안 됨. 그럴 때는 휴대폰 핫스팟을 쓸 것
- 아이패드용 포트는 8788(암호화), 노트북 화면용은 8787(이 PC 전용)
